Spent some time this weekend building an Elastic-based AWS SIEM lab.

Project consists of AWS infrastructure in Terraform and built around EC2, VPC, Security Groups, SSM, KMS, Secrets Manager, S3, and VPC Flow Logs, with Elasticsearch, Logstash, Kibana, and Filebeat forming the core of the stack.

The project was centered more on architecture, infrastructure security, and deployment design than on ingesting telemetry from multiple sources.

Trivy scanning for IaC is also integrated in CI/CD through GitHub Actions.

The project is on my GitHub:
https://github.com/Nicholas-devsec/AWS_ELASTIC_SIEM
